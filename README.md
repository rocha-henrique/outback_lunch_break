# 🍽️ Lunch Break Timer

Uma aplicação web criada para ajudar colaboradores a controlar o horário de retorno do almoço de forma simples, rápida e intuitiva.

O projeto foi pensado para uso real no dia a dia, com foco em **experiência mobile**, **feedback tátil**, e **interações naturais**, semelhantes às encontradas em aplicativos nativos.

---

## ✨ Funcionalidades

- ⏱️ Seleção de horário por roleta (scroll ou gesto de toque)
- 👆 Toque acima ou abaixo do valor para ajuste rápido
- 📳 Feedback háptico sutil ao alterar valores
- ⏰ Cálculo automático do horário de retorno
- 🔔 Alerta 5 minutos antes do retorno:
  - Vibração destacada
  - Notificação visual animada
  - Notificação do sistema (quando permitido)
- 💾 Persistência automática do último horário (localStorage)
- 📱 Layout 100% responsivo e otimizado para celular

---

## 🧠 Motivação

Este projeto não possui fins lucrativos.

Ele foi criado com o objetivo de ajudar colaboradores a lembrarem o horário correto de retorno do almoço, evitando atrasos e diminuindo a fricção do dia a dia no ambiente de trabalho.

---

## 🛠️ Tecnologias utilizadas

- React (Create React App)
- JavaScript (Hooks, Events, APIs do navegador)
- CSS puro (sem frameworks)
- Web APIs:
  - Vibration API
  - Notification API
  - localStorage
